Flujo para una familia nueva

  1. Padre entra a /app → "Crear familia"
  2. Recibe código de 6 caracteres
  3. Comparte el código con los hijos
  4. Teen entra → "Tengo código" → ingresa el código
  5. Cada miembro crea su perfil (nombre, edad, rol)
  6. El padre asigna un PIN para aprobar misiones

Registro de una escuela
