¿Qué es Evolución para el plantel?

Evolución es una plataforma de acompañamiento integral que conecta tres actores:

ActorQué obtiene
Alumnos (teens)Apoyo psicológico IA, tutor académico, orientación vocacional, detección de aptitudes
Padres de familiaPanel de seguimiento, misiones, señales de bienestar, chat de consejo parental
MaestrosClima del grupo, alertas anónimas, mapa de rezago, coaching pedagógico IA, módulo de bienestar docente
PlantelCódigo de escuela para vincular familias, módulos configurables (laico / canónico), reportes agregados

Registrar el plantel

Enviar solicitud de registro al administrador del sistema:

Contacto: milanmontellanoanuar@gmail.com

Información requerida:

  • Nombre oficial del plantel
  • Tipo: laico / religioso (carisma si aplica: ignaciano, marista, salesiano, etc.)
  • Nombre del responsable técnico de la institución
  • Número de grupos y alumnos aproximados

Se le asignará un código de escuela de 6 caracteres que compartirá con maestros y padres de familia.

💡 El registro técnico también puede hacerse vía API: POST /api/escuelas con los campos nombre, tipo y carisma.

API — Registro técnico directo

Registrar escuela

POST https://evolucion-v2.onrender.com/api/escuelas
{"nombre":"Colegio San Ignacio","tipo":"religioso","carisma":"ignaciano"}

Respuesta: código de escuela + ID interno

Vincular familia al plantel

POST /api/escuelas/{eid}/vincular/{fid}

Ver familias vinculadas

GET /api/escuelas/{eid}/familias

Registrar maestros

1
Comparte el código de escuela con el cuerpo docente
Cada maestro entra a evolucion-v2.onrender.com/maestro → "Registrarme" → ingresa el código.
2
El maestro llena su perfil
Nombre, materia(s), grado(s) que imparte. El sistema le asigna un ID de maestro.
3
Acceso inmediato a su panel
Sin aprobación adicional — el código de escuela actúa como llave de acceso controlada.

Registrar familias

1
Comparte el código de escuela con los padres de familia
En junta de padres, circular, o WhatsApp. El código es el mismo para toda la institución.
2
El padre crea su familia
Entra a /app → Crear familia → ingresa el código de escuela al final del registro. Su familia queda vinculada automáticamente al plantel.
3
Los hijos se unen
El padre comparte su código de familia (6 letras) con sus hijos. Cada hijo crea su perfil.

Privacidad y protección de datos

✅ El plantel nunca accede al contenido de conversaciones de alumnos o padres. Solo recibe datos agregados: clima emocional del grupo, distribución de aptitudes, materias con rezago — todos anónimos y sin identificar alumnos específicos.

⚠ El módulo de bienestar docente es completamente privado. La dirección del plantel no tiene acceso a lo que los maestros escriben en ese módulo.
