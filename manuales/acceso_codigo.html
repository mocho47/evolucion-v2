Archivo principal: evolucion_server.py

Todo el backend está en un único archivo Python. Secciones principales:

SecciónContenido
Importaciones y configFastAPI, aiosqlite, httpx, dotenv, cors
init_db()Creación de todas las tablas SQLite con WAL mode
PROMPTSPROMPT_TEEN, PROMPT_PADRE, PROMPT_MAESTRO, PROMPT_MAESTRO_BIENESTAR
BURNOUT_PATRONES28 frases en español para detección de burnout docente
ai_query()Motor IA: Z.ai → Groq → Ollama (fallback encadenado)
detectar_senales()Análisis de mensajes de teens para alertas psicológicas
detectar_burnout_maestro()Análisis de mensajes de maestros para burnout
Endpoints /api/40+ rutas REST: familias, miembros, misiones, acuerdos, metas, deseos, señales, maestros, escuelas
Rutas HTMLGET /, /app, /maestro, /jorge, /manuales/*, /deck/*

Variables de entorno (NO en git)

VariablePara qué sirveDónde configurar
GROQ_API_KEYIA fallback (Groq llama-3.3-70b).env local + Render env vars
ZAI_API_KEYIA primaria (Z.ai GLM-4-flash).env local + Render env vars

Para ejecutar localmente: crear archivo .env con ambas variables. Para nube: configurar en Render dashboard → Environment.

Cómo ejecutar localmente

Requisitos

  • Python 3.12+
  • pip install -r requirements.txt
  • Archivo .env con GROQ_API_KEY y ZAI_API_KEY

Arrancar el servidor

cd C:\evolucion
python evolucion_server.py

El servidor levanta en http://localhost:8080. Panel: /app. Panel maestro: /maestro.
